轻量 WordPress 邮件插件，支持 Brevo API、Resend API、普通 SMTP 和 GitHub Release 后台更新。

== Installation ==
上传 GitHub Release 附件 mmm-wp-mail.zip 并启用，在“设置 → MAO-WP-MAIL”中配置发送方式。

== Changelog ==
= 1.1.0 =
插件显示名称改为 MAO-WP-MAIL，增加独立备用通道和失败后自动切换。

= 1.0.1 =
增加可选 GitHub Token 常量，以支持共享出口的 API 限流环境。

= 1.0.0 =
初始版本：三种发送方式、加密凭据、测试邮件和 GitHub 更新。
